# French and English (français et anglais)

## Radio and mesh terms in French (termes radio et maillage en français)

mesh network = réseau maillé; node = nœud; repeater = répéteur; room server =
serveur de salon; companion radio = radio compagnon; antenna = antenne;
frequency = fréquence; bandwidth = largeur de bande; spreading factor =
facteur d'étalement; coding rate = taux de codage; transmit power = puissance
d'émission; signal strength = force du signal; noise = bruit; channel = canal;
direct message = message direct (message privé); flood = inondation
(diffusion); path = chemin; hop = saut; advert = annonce; region = région;
public key = clé publique; private key = clé privée; password = mot de passe;
firmware = micrologiciel; battery = batterie (pile); charger = chargeur.

## Common MeshCore tasks in French (tâches MeshCore courantes)

ajouter une région = add a region: region put <nom> [parent], puis region
save. supprimer une région = remove a region: region remove <nom>. permettre
l'inondation (autoriser le flood) pour une région = allow flooding:
region allowf <nom>. bloquer l'inondation = block flooding: region denyf
<nom>. définir la région d'accueil = set the home region: region home <nom>.
changer la puissance d'émission = change transmit power: set tx <dBm>.
redémarrer le répéteur = reboot the repeater: reboot. envoyer une annonce =
send an advert: advert. Les détails sont dans les notes MeshCore (en anglais).

## Emergency phrases in French (phrases d'urgence en français)

Help! = Au secours! / À l'aide! Call an ambulance = Appelez une ambulance.
Call 911 = Faites le 911. I am hurt = Je suis blessé (blessée). Someone is
not breathing = Quelqu'un ne respire pas. Fire! = Au feu! Where is the
hospital? = Où est l'hôpital? I need a doctor = J'ai besoin d'un médecin.
Is anyone hurt? = Y a-t-il des blessés? We need water, food, shelter = Nous
avons besoin d'eau, de nourriture, d'un abri. I am safe = Je suis en sécurité.
Evacuate = Évacuez. Stay inside = Restez à l'intérieur.

## Everyday phrases in French (phrases courantes, comment dire en anglais)

Hello / good morning = Bonjour; good evening = Bonsoir; hi / bye (familiar) =
Salut; goodbye = Au revoir; please = S'il vous plaît; thank you = Merci;
you're welcome = De rien / Bienvenue (Quebec); yes / no = Oui / Non; excuse
me = Excusez-moi; I don't understand = Je ne comprends pas; do you speak
English? = Parlez-vous anglais?; how much is it? = Combien ça coûte?; where
is ...? = Où est ...?; my name is ... = Je m'appelle ...; can you help me? =
Pouvez-vous m'aider?

## Numbers, days and times in French (nombres, jours et heures)

1 un, 2 deux, 3 trois, 4 quatre, 5 cinq, 6 six, 7 sept, 8 huit, 9 neuf, 10
dix, 20 vingt, 30 trente, 50 cinquante, 100 cent, 1000 mille. Monday lundi,
Tuesday mardi, Wednesday mercredi, Thursday jeudi, Friday vendredi, Saturday
samedi, Sunday dimanche. Today aujourd'hui, tomorrow demain, yesterday
hier, morning matin, evening soir, night nuit. Times use the 24-hour clock:
15 h 30 is 3:30 pm.

## Directions and places in French (directions et lieux)

north nord, south sud, east est, west ouest; left gauche, right droite,
straight ahead tout droit; near près, far loin; road route, street rue,
bridge pont, river rivière, hill colline, mountain montagne, town ville,
village village, school école, church église, shelter abri, pharmacy
pharmacie, grocery store épicerie, gas station station-service (poste
d'essence).

## Weather words in French (météo, quel temps)

weather météo (temps); rain pluie; snow neige; freezing rain verglas (pluie
verglaçante); wind vent; storm tempête (orage for a thunderstorm); fog
brouillard; cold froid; hot chaud; heat wave canicule; flood inondation;
warning avertissement (alerte); power outage panne de courant (panne
d'électricité).
